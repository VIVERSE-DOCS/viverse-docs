# Unity WebGL on VIVERSE

This address is packaging and upload. A Unity game uses `AuthManager`, `CloudSaveClient`, and `LeaderboardClient` in the [VIVERSE Unity SDK](https://docs.viverse.com/developer-tools/unity/viverse-unity-sdk). Do not create a `.jslib` for login, cloud save, or leaderboards.

Build and upload steps are in the [Unity WebGL publishing guide](https://docs.viverse.com/standalone-app-publishing/unitywebgl-examples).
