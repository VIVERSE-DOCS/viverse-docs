# Unity WebGL examples

This address is kept for older links. It is packaging and upload, not a second getting-started guide. A Unity game uses `AuthManager`, `CloudSaveClient`, and `LeaderboardClient` in the [VIVERSE Unity SDK](https://docs.viverse.com/developer-tools/unity/viverse-unity-sdk). Do not create a `.jslib` for login, cloud save, or leaderboards.

Build and upload steps are in the [Unity WebGL publishing guide](https://docs.viverse.com/standalone-app-publishing/unitywebgl-examples).
