# VIVERSE Docs

This repo contains the open-sourced content from [docs.viverse.com](https://docs.viverse.com).

For a Unity game, use the current [VIVERSE Unity SDK](https://docs.viverse.com/developer-tools/unity/viverse-unity-sdk) for C#. Do not use the JavaScript SDK or a `.jslib` for normal Unity authentication, cloud save, multiplayer, leaderboard, or avatar integration. The JavaScript SDK is for three.js, PlayCanvas, and other browser JavaScript.
