# VIVERSE leaderboards

Using Unity? Use `LeaderboardClient` in the [VIVERSE Unity SDK](https://docs.viverse.com/developer-tools/unity/viverse-unity-sdk). Do not call `uploadLeaderboardScore` or `getLeaderboard` from Unity game code, and do not create a `.jslib`.

Using JavaScript, three.js, or PlayCanvas? Use the [JavaScript Leaderboard SDK](https://docs.viverse.com/developer-tools/javascript/leaderboard-sdk).
