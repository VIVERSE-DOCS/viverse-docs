# VIVERSE login

Using Unity? Use `AuthManager` in the [VIVERSE Unity SDK](https://docs.viverse.com/developer-tools/unity/viverse-unity-sdk). Do not call `checkAuth` or `loginWithWorlds` from Unity game code, and do not create a `.jslib`.

Using JavaScript, three.js, or PlayCanvas? Use the [JavaScript login guide](https://docs.viverse.com/developer-tools/javascript/login-and-authentication-for-the-sdk).
