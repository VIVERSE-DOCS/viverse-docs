# Legacy Unity SDK (v0.96)

These pages document VIVERSE Unity SDK v0.96. Do not use them for a new Unity project.

For a Unity game, use the [VIVERSE Unity SDK](../viverse-unity-sdk.md).

* [Cloud Save (v0.96)](unity-cloud-minimal-example.md). `CloudSaveService` is a legacy API. Use `CloudSaveClient`.
* [Authentication (v0.96)](unity-login-and-authentication-minimal-example.md). `LoginManager` is a legacy API. Use `AuthManager`.
* [Leaderboards (v0.96)](unity-leaderboard-minimal-example.md). `LeaderboardService` is a legacy API. Use `LeaderboardClient`.
